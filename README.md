# Frontend Development — Project 1

## Static Webpage Design

This project is a static webpage created for **DecodeLabs Frontend Development Project 1**.

The project follows the training kit's focus on semantic HTML, clean CSS structure, readable layout, accessibility, and responsive design.

## Objective

Create a static webpage using **HTML and CSS** with:

- Proper HTML structure
- Headings and semantic sections
- Images with descriptive alternative text
- Clean and readable layout
- External CSS styling
- Responsive design

## Technologies Used

- HTML5
- CSS3

No JavaScript is required because this is a static webpage project.

## Project Structure

```text
frontend-project-1/
│
├── index.html

├── README.md

    └── hero.webp
```

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

For VS Code, you can also use the **Live Server** extension.

## HTML Concepts Used

The page uses semantic elements including:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

The document uses one main `<h1>` and follows a logical heading hierarchy.

## CSS Concepts Used

The stylesheet demonstrates:

- External CSS
- CSS variables
- Box model
- CSS Grid
- Flexbox
- Responsive media queries
- Reusable classes
- Spacing and typography
- Hover/focus states

## Layout Approach

The page follows the **Input → Process → Output** idea:

1. **Input:** content and image assets
2. **Process:** semantic HTML + CSS engineering
3. **Output:** responsive visual webpage

CSS Grid is used for major page structures, while Flexbox is used for smaller alignments such as navigation.

## Accessibility

The project includes:

- Descriptive `alt` text for the main image
- Accessible navigation label
- Logical heading hierarchy
- Keyboard-friendly links
- Readable text and contrast
- Responsive layout

## Quality Checklist

- [x] Semantic HTML structure
- [x] One clear H1

- [x] No inline styling
- [x] Grid for major layout
- [x] Flexbox for component alignment

## Learning Outcome

This project demonstrates the ability to turn a webpage idea into a structured frontend implementation using HTML and CSS while keeping content, presentation, accessibility, and responsive behavior organized.
